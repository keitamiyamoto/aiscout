# 写真の置き場所

ここに置いた写真はトップページに自動で使われます (再デプロイで反映)。

| ファイル名 | 使う場所 | 目安 |
| --- | --- | --- |
| `hero.jpg` | ファーストビュー右側の人物写真 | 横1200px以上・人物が右寄り・背景がすっきりしたもの |
| `advisor-xxx.jpg` | キャリアアドバイザー紹介 (`src/content/advisors.ts` に登録) | 正方形 600px 以上・顔が中央 |

- 拡張子は jpg / png / webp どれでも可
- `hero` が無いあいだは、診断画面のイメージを表示します
